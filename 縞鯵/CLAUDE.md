## 固定仕様（全ページ共通・変えない）
- `.video-wrap` の背景は `var(--bg)`＝本文と同じ淡色
- 動画エリアの高さは `80vh` 基準（言語バーの高さを差し引く）
- 8言語対応（`ja`/`en`/`zh`/`ko`/`es`/`it`/`vi`/`tl`）。開いたときは**常に日本語**、選択は保存しない
- 国旗は**インラインSVG**（絵文字の国旗はWindowsのChrome/Edgeで描画されない）
- `.lang-name` のフォントは**ラテン系を先頭**（ベトナム語の「ế」が崩れるため）
- 名称の各言語表記は釣りゲーム `../../ざうおスマホゲーム/index.html` の `FISH_NAMES.shimaaji` に合わせる

## 表示確認の方法（Playwrightが入っていないため）
このマシンには playwright パッケージが無いが、**ブラウザのバイナリだけは入っている**
（`%USERPROFILE%\AppData\Local\ms-playwright\chromium-1234\chrome-win64\chrome.exe`）。

`chrome --headless --window-size=390,844 --screenshot` は**幅の指定が効かず504pxで描画される**
（画像だけ390pxに切られるので、本文が見切れて「バグっている」ように見える）。
正しくスマホ幅で見るには **CDP の `Emulation.setDeviceMetricsOverride`** を使うこと。
python の `websockets` + `requests` で足りる。手順は `縞鯵.md` の状態メモを参照。

実測値（390×844）: `scrollWidth` 390（横スクロールなし）／`.langbar` 111px ／
`.video-wrap` 564px（= 80vh − 111px、仕様どおり）
